# Documentación Funcional - Estrella Dorada

La plataforma "Estrella Dorada" es una aplicación web premium de premiación para Estrella Dorada (Asobares Quindío).

## Características principales

* **Layout Multilingüe:** Ofrece una experiencia de usuario (UX) adaptada a diferentes idiomas.
* **Cinematic Motion Scroll:** La sección principal de presentación del trofeo implementa un scroll cinematográfico dividido en 3 escenas secuenciales sincronizadas con el porcentaje de scroll. Ver detalles en la [Dirección Cinematográfica](file:///C:/Users/ivang/Desktop/Mare-Meua/Estrella%20Dorada/CINEMATIC_DIRECTION.md).
* **Componentes Principales:**
    * Hero (Página principal de bienvenida con Escena 1).
    * Premios (Sección detallada con Escena 2 y Escena 3).
    * Etc.

## Tecnologías

* Construido sobre Next.js App Router.
* Internacionalización usando `next-intl`.
